## Status meanings

- **VERIFIED** — the scoped behavior passed an automated test in this audit. This does not certify a live hotel deployment.
- **IMPLEMENTED_NOT_VERIFIED** — code or a contract exists, but this audit did not demonstrate its end-to-end behavior.
- **PARTIAL** — some acceptance points passed while a requested behavior or environment remains unverified.
- **MISSING** — no dedicated implementation was found for the stated capability.
- **BLOCKED** — acceptance depends on external systems, property data, credentials, hardware, or decisions unavailable here.

Mock data, browser stubs, and local provider fakes are identified as such and do not establish production functionality.
